# Slime Đại Chiến

Bản web được đóng gói từ file HTML bạn gửi. Mở `index.html` để chơi trên máy tính; trên điện thoại, mở đường link sau khi bật GitHub Pages và xoay ngang màn hình.

## Đưa game lên GitHub Pages

1. Tạo một repository mới trên GitHub, ví dụ `slime-dai-chien`.
2. Tải `index.html` lên thư mục gốc của repository.
3. Mở **Settings → Pages**.
4. Ở phần nguồn xuất bản, chọn **Deploy from a branch**, nhánh `main`, thư mục `/(root)`, rồi bấm **Save**.
5. Sau khi GitHub hoàn tất, trang sẽ có địa chỉ dạng `https://TEN-TK.github.io/slime-dai-chien/`.

GitHub Pages là trang công khai. Bản game hiện chơi với bot; đăng lên web chỉ tạo link để mọi người tự chơi, chưa thêm đấu trực tuyến với nhau.
